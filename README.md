# SQL Learning Application

This project is designed to help users learn SQL through interactive exercises and tutorials.

## Project Structure

- `frontend/`: Contains the user interface and client-side logic.
- `backend/`: Houses the server-side application and API endpoints.
- `database/`: Stores database schemas, migrations, and seed data.
